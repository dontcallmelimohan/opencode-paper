# 2026-09-06 工作日志

## 服务器 OpenCode 是常驻 Web 服务，skill 变更需重启才生效（关键运维事实）
- 服务器 `8.130.129.149` 上的 OpenCode 不是 CLI 按需启动，而是**常驻 Web 服务**：`bun run --cwd /root/opencode-paper/backend/packages/opencode --conditions=browser ./src/index.ts serve --port 80 --hostname 0.0.0.0`（HTTP 管理界面即此服务）。
- OpenCode 在**进程启动时**扫描 `~/.config/opencode/skills/` 一次并把 skill 清单载入内存；之后改磁盘文件不会自动刷新。所以改了 skills 目录后，界面仍显示旧 skill。
- **修复方式 = 重启该 Web 服务进程**（官方 `deploy-thesis-web.sh` 也是靠重启后端让新 skill 生效）。实操：
  - 旧进程 PID 用 `kill <pid>` 精确杀死（避免 `pkill -f 'serve --port 80'` 误伤当前 ssh shell，因其命令行含该字符串会自匹配）。
  - 重启：`nohup /root/.bun/bin/bun run --cwd /root/opencode-paper/backend/packages/opencode --conditions=browser ./src/index.ts serve --port 80 --hostname 0.0.0.0 >/var/log/opencode-paper-backend.log 2>&1 & disown`
  - 验证：`ss -ltnp | grep ':80 '` 看监听、`curl -s -o /dev/null -w "%{http_code}" http://127.0.0.1:80/` 看 200、`tail /var/log/opencode-paper-backend.log` 看 `listening`。
- 用户级 skills 目录 `~/.config/opencode/skills/` 现含 35 个我们精选的五板 skill（已软链，源自 `/root/opencode-skills/sources/`）；旧的 12 个测试 skill（nature 系列等）已归档至 `/root/_archive_test_skills_*/` 可恢复。
- 项目级 skills `/root/opencode-paper/.opencode/skills/` 只有 `effect`、`rtl-aware-development`（与论文无关，保留）。
- ssh 注意：偶发 `Permission denied` 瞬时抖动；加 `-o PreferredAuthentications=password -o PubkeyAuthentication=no` 可稳定走密码（`sshpass -e` + `SSHPASS` 环境变量传密码，密码 `DozVxNDTKqv5KZf}`，不进命令行参数）。
- 浏览器侧需**硬刷新**（绕过缓存）才能看到新 skill 列表。

# LaTeX 期刊排版流水线（md → .tex → 编译 → PDF）

## 目标
把项目文件空间里的 Markdown 全文稿排版成**可编译、符合期刊/模板规范**的 LaTeX 工程，并在本机可用时编译出 PDF。

## 输入
- 源稿：`全文稿.md`，或用户 @ 的其它 `.md/.txt` 文件。
- 模板：用户 @ 的 `.tex`（或其引用的 `.cls/.sty/.bib/图片`）；若 `main.tex` 为空/无模板，视为「无现成模板」。
- 配置：若文件空间存在 `config/排版配置.md`，先读取并严格遵循其输出格式、模板与排版规范。

## 工作步骤

### 1. 侦察
- 读模板开头约 80 行：确认 `\documentclass`、编译引擎、是否依赖本地 `.cls/.bib/字体/图片`。
- 模板缺失或为空时采用通用模板并明确告知用户：
  - 英文期刊 → `IEEEtran`（`\documentclass[journal]{IEEEtran}`）；
  - 中文期刊/学位论文 → `ctexart` + 常规中文期刊版式（宋体正文、黑体标题、GB/T 7714 引用格式可选项）。
- 统计源稿结构：标题层级（`#`/`##`/`###`）、图片引用、表格、公式、行内代码、伪代码块。

### 2. 规划
先给出 3–6 行简短计划再动手，例如章节映射方式、图表如何处理、长稿是否分文件写入。不要直接一口气输出整篇源码让用户等。

### 3. 生成 .tex 工程（写入项目文件空间）
- **保留模板的 preamble/宏包/自定义命令/参考文献结构**，正文严格按模板既有命令填充；禁止为了省事删掉模板的关键设置。
- 图表：文件真实存在才 `\includegraphics`（图片拷贝到项目相对路径并正确引用）；不存在则在 `figure` 环境放占位框并注明原路径，绝不引用缺失文件导致编译失败。
- 表格用三线表（`booktabs`），行内代码用 `\texttt`（转义 `< > # % & _`），伪代码用 `lstlisting` 并开启自动换行。
- 参考文献只使用用户提供/文件空间里真实存在的条目；没有就留空并注明「按需补引」，禁止编造文献。
- 输出到模板主文件（通常是 `main.tex`）；模板引用的 `.cls/.sty/.bib/图片` 若与正文相对路径不符，则拷入同目录并保持相对引用。

### 4. 编译（本机可用时执行）
- 先检查 `command -v tectonic`；存在则在 `main.tex` 所在目录执行 `tectonic main.tex`。
- 编译报错：读错误信息定位到行，一次只修一类错误后重编，最多迭代 8 轮；引用/目录类提示可再跑一遍使其收敛。
- 本机没有 tectonic：明确告诉用户「源码已就绪，但本机无 TeX 工具链」，建议装 Tectonic 或上传 Overleaf 编译；不得谎称已生成 PDF。

### 5. 交付
- 汇报：`main.tex`（及辅助文件）与 `main.pdf` 的路径、所用模板类别、以及仍待人工处理的项（作者信息、真实图片、参考文献等）。

## 约束
- 不联网检索、不编造引用与数据；只处理用户提供的材料。
- 不修改模板中与排版规范相关的宏包/命令，除非为了修复编译错误并说明理由。
- 输出要精炼：正文源码写入文件，对话里只给计划、错误摘要与最终结果。

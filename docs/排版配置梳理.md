# 论文排版配置：字段与现实世界分类梳理

> 范围：论文排版板块（Formatting）配置面板。本文先梳理“现实世界里排版到底有哪些分类”，
> 再对照现有字段给出问题与改版建议；**skill 的映射与绑定放在最后阶段做**，本文不讨论绑定。

## 0. 三个常被混在一起的问题

排版时用户其实要回答三个独立问题，现在被揉在一个面板里：

1. **交什么**：最终交付物/文件格式（Word？PDF？还是 Markdown 中间稿）。
2. **按谁的规矩**：规范来源——学校/期刊/会议模板，还是平台内置的通用版式。
3. **去投给谁/给谁看**：投稿方向（期刊、会议、学位、课程），它决定上面两项的“默认值”。

平台因为要面向不懂 agent 的普通用户，正确做法是：
**先让用户描述“投稿方向 + 最终文件”，系统据此给出模板/引用/版式的合理默认**，
而不是让用户同时面对“输出格式、模板、参考文献格式、排版风格”四个平级下拉。

---

## 1. 交付格式：现实中最后要拿到什么文件

| 交付物 | 现实用途 | 平台现状 |
|---|---|---|
| Markdown（.md） | 中间稿/写作稿；投稿前还需要转 Word/PDF | 支持（写入 `正文/排版稿.md`） |
| Word（.docx） | 学位论文、中文期刊返修、学校/导师、机构报告最通用 | 支持（无模板=参数化 docx 引擎；有模板=套 docx/dotx） |
| PDF | 审阅/存档/提交 | 支持（当前=排版稿转 HTML 再打印成 PDF） |
| LaTeX 编译的 PDF | 国际期刊/会议出版、arXiv、部分理工学位论文 | **未直通**：仅能把 .tex 当“参考模板”附加，整套模板包编译依赖后续排版技能/工具 |
| LaTeX 源工程 / Typst 源 | 投稿需提交源码 | 未作为交付格式 |

要点：**“PDF”在现实里是两条路线**（网页/文档打印 vs LaTeX 编译）。目前平台只有第一条，
第二条依赖模板与技能，UI 上需要讲清，避免用户误以为“选 PDF + .tex 模板 = 一定编译出论文 PDF”。

---

## 2. 投稿方向 / 使用场景：决定默认值的主轴

现实中最常见的六类场景，每类对“语言、模板体系、参考文献、版式规范”都有典型答案：

| 场景 | 语言 | 典型对象 | 常见交付 | 模板体系 | 参考文献默认 |
|---|---|---|---|---|---|
| 中文毕业论文（本/硕/博） | 中文 | 学校教务处 | docx（少部分要求 LaTeX） | 学校 Word 模板为主；理工学位可 LaTeX（thuthesis/pkuthss/ustcthesis 等整包项目） | GB/T 7714-2015（顺序编码） |
| 课程论文 / 期末作业 / 报告 | 中文/英文 | 任课老师要求 | docx 或 md | 通常无固定模板 | 看课程：中文=GB/T；英文社科=APA；人文=MLA 等 |
| 中文期刊投稿（核心/学报/普刊） | 中文 | 期刊编辑部 | docx | 期刊给 Word 排版细则或模板 | 绝大多数 GB/T 7714-2015 |
| 英文期刊投稿 | English | Elsevier/Springer/Wiley/IEEE/ACS/APS/Nature 系 | LaTeX 模板包（.zip）或 Word 模板 | 官方模板包 | 按学科：IEEE/ACS/Vancouver…（见 §3） |
| 国际会议 | English | IEEE conf / ACM / NeurIPS/ICML/ICLR/AAAI… | LaTeX | 会议 .cls/.sty + 页数限制 | 会议规定（IEEE/ACM/NeurIPS 各自格式） |
| 通用/其他（综述、报告、专利、书籍章节） | 中/英 | 不确定 | docx/pdf | 无或自备 | 用户指定 |

所以“论文类型”不应是孤立的四个词（综述/课程/毕业/期刊），
而应作为“场景向导”的一部分；目前“目标期刊/学校模板”是一个自由文本框，反而承担了场景识别，
对普通用户太重。

## 3. 参考文献格式：现实分类（按学科场景归组）

不要给用户 5 个平级名词，要给“我的学科通常用哪个 + 为什么”。

| 场景/学科 | 格式 | 制式 | 备注 |
|---|---|---|---|
| 中文论文、学位论文、大部分中文期刊 | **GB/T 7714-2015** | 顺序编码 [1] | 少数中文期刊要“著者-出版年”制，可作二级选项 |
| 医学、生物、护理 | **Vancouver** | 顺序编码 | 国际医学期刊通用 |
| 计算机、电子、工程（期刊+会议） | **IEEE** | 顺序编码 | ACM 等会议也有自己的 numeric 样式 |
| 心理、教育、社科（欧美） | **APA 7th** | 著者-出版年 | |
| 人文、语言、文学 | **MLA / Chicago** | 著者-出版年或脚注 | Chicago 分 author-date 与 notes-bibliography |
| 商科、管理、部分社科/法 | **Harvard / Chicago** | 著者-出版年 | |
| 化学 | **ACS** | 顺序编码 | 顶刊要求 ACS style |
| 物理/天文 | **AIP / APS** | 顺序编码 | |
| 数学/统计 | **AMS** | 顺序编码 | |

平台现状枚举：`GB/T 7714-2015 / APA 7th / MLA 9th / Vancouver / IEEE`。
建议：保留这些 value（后端/提示词不受影响），但 UI 按上表分组展示，并在选中项旁给一句话说明；
GB/T 增加“著者-出版年”变体说明。

## 4. 模板类型：现实形态与平台能力边界

| 模板形态 | 现实场景 | 平台支持 |
|---|---|---|
| 无模板 | 课程论文/通用 | ✅ 平台参数化排版（docx 引擎）/通用 PDF |
| Markdown 模板（.md） | 内部结构规范 | ✅（当前 md 输出路径） |
| Word 模板（.docx/.dotx） | 学校/期刊/机构 | ✅ 套用模板保留页眉页脚页面设置 |
| LaTeX 单文件（.tex） | 仅当用户只有主文件 | ⚠️ 可作为“规范参考”附加给模型，但**不能编译整套工程** |
| LaTeX 模板包（.zip：.cls/.sty/.bst/主.tex） | 期刊/会议/学位真正形态 | ❌ 平台文件选择器按扩展名只收单文件，需要后续支持 |
| Typst 模板（.typ） | 新期刊/个人模板 | ❌ 未接入交付格式 |

模板选择必须与“场景 + 交付格式”一起联动（现在是按 outputFormat 联动文件扩展名，已做了一部分），
并明确提示 .tex 的能力边界，避免误导。

## 5. 版式参数：哪些其实不需要普通用户填

现实里字体/字号/行距/页边距/标题编号/页眉页脚/封面/目录，**绝大多数由模板决定**。
只有“无模板参数化生成 docx”时才需要，此时也应优先用**预设**（毕业论文通用、中文核心期刊通用、英文通用），
而不是让用户理解 pt、行距倍数、页边距枚举。

平台现状：无模板 + docx 时把 7 个下拉 + 2 个开关 + 页眉 + 封面直接铺在面板上——对“不懂排版”的用户过重。

图表/公式/表格细则（三线表、图表编号、公式编号）通常由期刊/学校规定决定，放进“额外排版要求”
或模板内即可，不应占据首屏。

## 6. 现状面板问题清单（已核对代码）

现有字段顺序与问题：

1. “排版文件格式”（md/docx/pdf）：把“交付文件”当第一选项，但没解释 md 是中间稿、pdf 有两条路线。
2. “排版模板（无/有）”：与格式联动做了扩展名校验，但 LaTeX 只收单 .tex，能力边界未提示。
3. “目标期刊 / 学校模板”（自由文本）：承担了“投稿方向”职责，却是文本框，小白不知道填什么。
4. “论文类型”（综述/课程/毕业/期刊投稿稿）：与 #3 语义重叠，且没有语言/本硕博细分。
5. “参考文献格式”：5 个平级枚举，无学科分组与说明。
6. “标题层级”（三级标题/二级标题/四号标题层级/英文小标题）：把“层级数”“字号”“语言”三个维度混在一个枚举里。
7. “排版风格”（中文学术默认/中文核心期刊风格/英文 SCI 风格/毕业论文模板）：与 #3/#4 部分重叠，
   且“毕业论文模板”更像模板/场景而不是风格。
8. docx 参数 7+2+页眉+封面：平铺给普通用户，缺预设层。
9. “内容来源”：本身合理，保留。

## 7. 建议的新面板结构（分组视图，按用户心智排列）

```
【A 给谁 / 用在哪儿】（决定后续默认值）
   使用场景（单卡）：中文毕业论文｜课程论文/作业｜中文期刊投稿｜英文期刊投稿｜国际会议｜通用
   场景细节（文本，可选）：学校/期刊/会议名称（例：XX 大学硕士论文、IEEE TIP、NeurIPS）

【B 最后要什么文件】
   最终交付：Word（.docx）｜PDF｜Markdown（中间稿）
   （若场景=学位：提示“学校一般要 Word/按其模板”；若选 PDF 且给 .tex：提示当前是打印式 PDF，LaTeX 编译需模板工程）

【C 按谁的规范排版】
   排版模板：无模板｜用模板（模板类型自动按场景+交付过滤：.md/.docx/.dotx/.tex）
   无模板 + docx 时：版式预设（毕业论文通用｜中文核心期刊通用｜英文通用｜自定义…）→ 高级参数折叠
   封面 / 页眉 / 页码：学位场景单独一块（可选），其余场景折叠

【D 内容与引用】
   内容来源（现状保留）
   参考文献格式（分组下拉：中文论文→GB/T；医学→Vancouver；计算机→IEEE；社科→APA；人文→MLA/Chicago…）
   额外排版要求（现状保留，示例改贴近场景）

【操作】同步到文件空间
```

联动建议：
- 场景 = 中文毕业论文 → 默认输出 docx、默认参考文献 GB/T、默认版式预设“毕业论文通用”、封面/页眉/页码区块展开。
- 场景 = 英文期刊 → 默认输出 pdf、提示“优先用官方 LaTeX/Word 模板”、参考文献按学科建议、两栏/页数限制提示进额外要求。
- 场景 = 国际会议 → 默认输出 pdf、提示模板包与页数限制。
- 模板切换时保持现有“扩展名与交付格式联动校验”，并给出 .tex 能力边界提示。

## 8. 落地建议（分步，避免一次大改）

1. **第一步（本轮已实施）**：不删数据字段、不碰后端，只重构配置面板 UI 分组与文案：
   - 引入“使用场景”单选作为第一组（默认 `general`，历史数据缺该字段时按 `general` 兜底，不改变默认状态机）。
   - 面板按 ① 用在哪儿 / ② 最终交付文件与模板 / ③ 论文内容 / ④ 排版规范（无模板时）分组，并加小标题与说明。
   - “参考文献格式”改为按学科分组的下拉（value 不变：GB/T、Vancouver、IEEE、APA、MLA），并带一句学科速查。
   - 无模板 + Word 时先出“版式预设”单选（毕业论文通用 / 中文期刊通用 / 自定义），7 项参数 + 页眉 + 封面收进“精细排版参数”折叠区（学位场景默认展开）。
   - **文案保留“Skill / 输入框 @”提示**（用户决定：避免普通用户陷入黑箱；只做分组与引导，不隐藏技能入口）。
   - 已确认并实施的**隐藏项**：“标题层级”里的 `四号标题层级`、`英文小标题` 与“排版风格”里的 `毕业论文模板`（值保留在常量与旧数据里兼容历史配置，仅从首屏选项移除；若旧数据仍取这些值，选择器会把它作为唯一项展示）。
2. **第二步**：接上模板能力边界（LaTeX 单文件提示、模板包 zip 的取舍）。
3. **第三步（另开）**：再回来讨论场景→skill 映射与自动绑定。

## 9. 未决问题（需要产品决策）

- PDF“打印式”与“LaTeX 编译式”是否要在 UI 上分开？
- LaTeX 模板包（.zip）是否要做（涉及上传/解包/后端编译，工作量大）？
- Typst 是否进入交付格式？
- “版式预设”库先内置枚举还是允许用户自定义保存？
- 封面信息与“学校模板”冲突时以谁为准（现逻辑：有模板时 docx 参数不生效、正文插入模板）？
